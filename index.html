Hakkımda

Bilecik Şeyh Edebali Üniversitesi Bilgisayar Mühendisliği mezunuyum. Yazılım geliştirme kariyerimde kurumsal ölçekli web uygulamaları, yüksek performanslı arka uç (backend) servisleri ve veri odaklı otomasyon çözümleri üzerine odaklanıyorum.

İstanbul Teknik Üniversitesi (İTÜ) bünyesinde kurumsal web mimarilerinin geliştirilmesi, RESTful API entegrasyonları ve veritabanı optimizasyonu süreçlerinde görev alıyorum. Boş zamanlarımda ise Python ile finansal veri analizi botları ve HTML5 Canvas tabanlı tarayıcı oyunları tasarlıyorum.
